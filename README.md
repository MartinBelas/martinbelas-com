# MyPortfolio

Static professional website for Martin Belas. Open index.html locally; no build or dependencies are required.

## Deployment targets

- https://martinbelas.com/ — this portfolio on GitHub Pages.
- https://www.martinbelas.com/ — redirects to the canonical portfolio domain.
- https://ai-demo.martinbelas.com/ — the separate AI Demo application on Google Cloud Run.

These are intended targets, not a confirmation that deployment is live.
